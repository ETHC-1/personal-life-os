# 重复日程与基础提醒

- 日期：2026-09-01
- 状态：已完成

## 背景

编辑能力完成后，需要让日历支持常见重复安排，并为未来通知渠道提供统一的提醒计算结果。

## 实现范围

- 支持不重复、每天、每周和工作日四种规则。
- 重复日程必须设置结束日期，查询时展开为具体发生时间。
- 支持设置提前 0—10080 分钟提醒。
- 新增 `GET /api/reminders`，返回事件、发生时间和提醒时间。
- 首页日程表单增加重复和提醒配置。

## 决策

当前只实现 MVP 所需的固定规则，不引入完整 RFC RRULE 解析器；提醒先由后端计算，不直接发送手机、邮件或手环通知。这样可以保持依赖轻量，并为后续通知 worker 保留稳定接口。

## 验证结果

重复事件展开、提醒时间计算、时区处理和既有日历/待办/课表测试均通过，共 26 项 Python 测试；前端 JavaScript 语法检查通过。
