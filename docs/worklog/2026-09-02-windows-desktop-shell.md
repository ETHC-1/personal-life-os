# Windows 桌面端壳

- 日期：2026-09-02
- 状态：已完成 MVP 骨架

## 背景

项目已经有可用的 Python Web MVP，桌面端需要复用现有业务页面，避免维护第二套日历、待办和课表逻辑。

## 决策与原因

采用 Tauri 2 作为 Windows 桌面壳。桌面进程只负责启动监听回环地址的本地 Web 服务和承载窗口；WebView 不开放 Shell、任意文件系统或命令执行能力。

## 验证结果

已新增 `desktop/src-tauri` 工程、最小 capabilities、启动脚本和桌面端说明。构建验证需要本机安装 Tauri CLI 和 Rust 依赖，后续可运行 `desktop/launch-desktop.ps1`。

## UI 更新

桌面端改为蓝白视觉系统，关闭系统默认标题栏，加入自定义拖拽标题栏、最小化/最大化/关闭控制、无边框透明窗口和圆角布局；侧边栏预留 AI 助手与同步中心入口。

随后将桌面端从 Web 页面移植模式调整为独立 UI：Tauri 加载 `desktop/ui`，桌面 UI 通过 `127.0.0.1:8765` 读取现有后端数据，保留共享业务服务但独立组织桌面信息架构。
