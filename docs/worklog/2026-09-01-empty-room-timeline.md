# 空教室时间轴连续条带

- 日期：2026-09-01
- 状态：已完成

## 背景

原时间轴按单个课时渲染占用条，即使相邻课时连续占用，也会看起来像多个独立方块。

## 实现

- 在前端按课时编号排序并合并相邻占用课时。
- 合并条带覆盖从首个课时开始到末个课时结束的完整时间范围。
- 保留 `title` 和 `aria-label`，鼠标悬停可查看教室、时间范围和占用状态。
- 悬停时在条带内显示时间范围，并增加轻微高亮效果。

## 验证

- 检查前端 JavaScript 修改和 CSS 差异。
- 后续打开 `http://127.0.0.1:8000/` 并刷新空教室数据，确认相邻课时显示为连续条带。
