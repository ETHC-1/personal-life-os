# 移动端空教室 H5

- 日期：2026-09-04
- 状态：已完成

## 背景

原空教室页面以全天时间轴为主，手机用户仍需要自行寻找日期和课时，查询路径较长。

## 决策

保留现有 `/api/empty-rooms` 和 `/api/periods`，将独立页面调整为移动端结果优先：今天默认定位当前时间对应的课时，首屏显示可用教室，时间轴收纳到“查看全天时间轴”中。通过 URL 参数保留楼栋、日期和课时选择，方便分享固定查询链接。

## 验证

- 页面静态资源继续使用项目现有打包配置。
- 待运行 JavaScript 语法检查和 Python 测试。

## 追加修复

9 月 5 日接口响应显示，`jxcdxxList` 包含东教学楼完整的 19 间教室，而 `jszylist` 只有实际有安排的记录。原解析器按嵌套字段顺序扫描，误把 `jszylist` 当成教室清单，导致未来日期只保存 1 间教室。现已让 `jxcdxxList` 专门提供教室目录、`jszylist` 专门提供占用课时，并增加回归测试。

随后根据教务页面核对发现，部分活动记录的 `jxcdmc` 为空，但 `jxcddm` 与完整清单中的教室编号一致。解析器现会通过 `jxcddm` 补全教室名称，覆盖活动对 1—4 教室的占用情况。

补充排除没有任何课时的目录记录，避免建华校区出现“占用记录数量很多但占用课时为空”的误导性统计。`sytype` 不做过滤，课程和活动记录均按课时参与占用计算。
