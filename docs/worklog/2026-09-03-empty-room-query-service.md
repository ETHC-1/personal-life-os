# 空教室定时查询服务

- 日期：2026-09-03
- 状态：已完成

## 背景

项目已能通过教务接口抓取教室占用记录，需要一个可在 Ubuntu 服务器定时运行、并向手机或其他设备提供查询结果的小型服务。

## 目标

- 06:00—21:00 每小时抓取当天和次日数据。
- 使用原子 JSON 快照解耦抓取 worker 和 Web 请求。
- 提供独立响应式 HTML 页面和可供设备集成的 JSON API。
- 不在项目、快照或日志中保存 Cookie/token。

## 决策与原因

使用 systemd timer 调度 oneshot worker，而不在 Web 进程中运行定时线程。这样抓取失败不会中断已缓存页面，也可以通过 journalctl 单独排查。Web 层对快照再次白名单清洗，避免未来抓取数据结构变化时意外向设备暴露原始字段。

## 验证结果

- Python 单元测试覆盖多日快照清洗、无效课时过滤和私有字段移除。
- 前端 JavaScript 通过 Node 语法检查。
- 打包检查确认 HTML/CSS/JS 静态资源会进入 Python wheel。

## 后续事项

- 部署时配置域名、HTTPS 和 Nginx 身份验证。
- 教务凭证过期后需要手动更新服务器环境文件。
