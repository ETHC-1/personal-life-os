# 基础 Web 前端

- 日期：2026-09-01
- 状态：已完成

## 背景

项目已有课程导入、校验和 JSON 存储能力，但没有可视化入口，难以快速验证课表数据。

## 目标

提供一个无需安装前端依赖即可运行的基础页面，并让页面读取现有最终课表文件。

## 决策与原因

- 使用 Python 标准库 HTTP 服务，避免在初始化阶段引入大型 Web 框架。
- 使用原生 HTML/CSS/JavaScript，覆盖今日概览、周课表、课程库和提醒预览。
- 当本地课表文件不存在时使用明确标记的演示数据，方便第一次启动体验；真实文件存在时只读取真实数据。

## 验证结果

- 已增加 `python -m personal_life_os.web` 与 `personal-life-os-web` 启动入口。
- 页面 API 提供 `/api/health` 和 `/api/courses`。
- 已补充前端课表导入面板、文件导入 API 和河北医科大学浏览器抓取 API；浏览器登录仍由用户手动完成。
- 修复浏览器导入接口遗漏导入器依赖以及异常返回 HTML 导致前端 JSON 解析失败的问题。
- 根据当前认证可用性，将浏览器导入入口切换为河北医科大学校园网首页，不再直接拉起 CAS 统一认证链接。
- 新增独立空教室抓取器和 `course-import empty-room` 命令，先验证 `classroom` 接口链路，暂不复用登录会话或合并 Web 前端。
- 新增共享 `HebmuBrowserSession`，课程和教室使用数据在同一浏览器登录会话中连续抓取；Web 端新增一次登录抓取两类信息的表单。
- 前端新增东教学楼 1—19 教室、13 课时的时间轴矩阵，后端仅向前端返回教室名和占用节次。
- 按需求优化矩阵布局：教室 1—19 纵向排列、时间横向排列，各课时使用竖向虚线贯穿标记。
- 按阶段需求暂限定东教学楼，并将合并抓取的教室查询日期改为今天和明天两天，前端提供日期切换。
- 根据视觉需求将空教室矩阵改为 06:00—24:00 均匀时间轴：占用时段使用橙红渐变进度条，空闲留白，课时边界使用竖向虚线。
- 已运行 Python 测试并进行 HTTP smoke test。
- 排查“全部显示空闲”：后端解析器现在兼容顶层 `jsylist`、`data.jsylist`、`data` 数组及字符串 JSON，并从 `jcdm2` 等字段提取 1—13 节；前端按去空白后的教室名匹配，避免接口名称格式差异导致占用条丢失。
- 验证结果：8 个课程相关单元测试通过；已重启本地 Web 服务加载最新后端代码。
- 根据实测响应补充 `jxllist` 字段解析；此前“0 个有使用记录”是字段名不匹配造成的。
- 继续兼容接口可能存在的多层包装和字符串化 JSON，并按教室名称字段筛选真实使用记录；新增对应回归测试。
- 根据 Fiddler 截图增加 `jsyzlist` 和未知列表键的兼容；无需复制完整响应，后续只需提供开头字段名和一条完整记录即可继续核对。
- 根据用户提供的实际响应确认列表字段为 `jszylist`，并补充解析测试；样例中的 `东教学楼5教室`、`03,04` 可直接生成占用条。
- 运行诊断确认实际空教室响应仅含 `code`、`msg`；增加安全状态回传，让页面展示校园网接口消息以定位请求参数或权限问题。
- 接入页面请求级 token 捕获：会话监听登录后页面请求中的 `token`，只在当前内存会话中附加到课程/空教室 API 请求，不落盘、不打印。
- 增加微信授权回调链接的临时输入支持；链接仅随本次本地请求传递，并限制为学校 `/app/` HTTPS 地址。
- 按需求将云端空教室抓取与课表抓取分离，新增持久化浏览器 Profile 的 `empty-room-poll` worker；支持首次手动授权、后续无密码轮询、结果写入项目外 JSON，默认 06:00—21:00 每小时查询今天和明天。
- Web 前端新增 `/api/empty-rooms`，读取本地 Fiddler 桥的脱敏快照；页面启动和右上角刷新会自动加载，避免依赖课表导入流程。
- 为验证无浏览器轮询路径，新增 `empty-room-direct-probe`；它使用当前会话的临时环境变量调用 `getIstoken` 和 `classroom`，仅输出状态、字段和统计数量，不保存原始响应。
- 根据 Fiddler 响应中的 `jxcdxxList` 和 `jcList`，新增 `empty-room-direct` 一次性直接抓取今天/明天的脱敏快照，并让 Web 接口兼容多日格式。
- 新增 Fiddler 本地桥接方案：只接收本机代理转发的空教室响应，Python 端剥离课程/认证字段后保存或可选上传；课表抓取链路未改变。
- 根据 Fiddler 发现的 `GET /dev-api/appapi/getIstoken`，浏览器会话现在会先主动获取 token，并以内存值附加到后续请求；新增 token 响应解析测试。
- 增强 Fiddler 桥脚本：在响应离开 Fiddler 前用正则提取并重建最小 JSON，仅保留 `jxcdmc`、`jcdm2`、`rq`，避免将姓名、课程和认证字段发送到本机桥。
- 根据实际桥接错误补充 GB18030 回退解码，兼容 Fiddler/Windows 本地编码发送的中文 JSON。
- 验证通过：桥接收到 `jszylist`，解析 42 条记录、13 个教室、87 个占用课时；敏感字段未进入保存结果。
- 增加不含敏感数据的服务端诊断日志，仅记录每日教室记录数、有效教室数和占用课时数，用于核对线上运行时的实际响应。
- 当前运行日志确认两次空教室请求均为 0 条可识别记录；追加记录响应顶层字段名和类型（不记录响应内容），用于判断同一登录会话下接口返回是否变化。
