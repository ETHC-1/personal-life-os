# 课程抓取与管理核心

- 日期：2026-09-01
- 状态：已完成基础能力，待接入学校教务系统

## 背景

项目当前没有前端、后端或既有依赖，需要先建立可以被后续接口和界面复用的课程领域模块。

## 决策与原因

- 使用 Python 标准库实现，暂不引入 HTTP、HTML 解析或数据库依赖。
- 通过 `CourseSource` 协议隔离学校系统；后续只替换登录、请求和页面解析适配器。
- 内部使用带时区的 `datetime` 计算提醒，避免生成无时区时间。
- 课程表解析支持常见中英文列名，但学校特有页面仍需单独适配。

## 当前能力

- 解析常见 HTML 课程表
- 课程、上课周次、星期、节次、教室和教师建模
- 导入时新增、更新、跳过未变化课程
- 在时间范围内生成课前提醒
