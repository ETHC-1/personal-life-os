# 课表自动抓取与自主导入

- 日期：2026-09-01
- 状态：已完成

## 背景

项目需要同时支持河北医科大学教务系统自动抓取和用户自主上传课表，并将两类输入统一沉淀为后续日程、提醒和 Agent 可使用的最终课表。

## 目标

- 用户手动完成 CAS 登录后，由可见浏览器抓取课表。
- 支持从 JSON、HTML 文件导入课表。
- 两种来源写入同一个最终课表文件。
- 为未来迁移到服务器存储和 Agent 受控修改保留清晰边界。

## 过程记录

- 根据浏览器 Network 记录确认教务系统课表接口：
  `POST https://jwweb.hebmu.edu.cn/new/student/xsgrkb/getCalendarWeekDatas`。
- 确认接口使用登录后的 `JSESSIONID` 会话，而不是观察到 OAuth access token。
- 确认学校存在 CAS 入口，但第三方 `service` 注册权限仍需学校确认。
- 新增 `FinalScheduleStore`，将最终课表保存为带 schema 版本和 UTC 更新时间的 JSON 文件。
- 新增学校 API 响应到领域模型的转换逻辑，避免持久化原始系统标识和原始响应。
- 新增 `HebmuBrowserImporter`：启动可见 Chromium，用户手动输入账号、密码和验证码，登录成功后在同一页面上下文请求课表。
- 新增 `course-import` 命令行入口，统一支持文件导入和学校浏览器导入。

## 决策与原因

- 默认最终课表存放在用户目录下的 `.personal-life-os/final_schedule.json`，避免个人数据进入代码仓库。
- 浏览器抓取采用用户在官方窗口中完成认证，不由后端保存密码、验证码或 Cookie。
- Playwright 作为可选依赖，避免基础课程领域模块引入不必要的大型依赖。
- 目前支持 JSON 和 HTML；后续可在明确字段映射后增加 Excel/CSV 或 Web 上传界面。
- Agent 后续只能通过课表服务的校验接口修改最终课表，不直接操作浏览器会话或数据库。

## 验证结果

- 课程领域测试通过：5 项。
- 验证了课程对象 JSON 序列化和反序列化。
- 验证了河北医科大学课表响应字段的基本映射。
- 验证了最终课表文件的原子写入和读取。
- 已将本地学校认证存档文件加入 `.gitignore`。
