# 空教室时间轴视图细化

## 背景

根据服务器实际截图，进一步调整东教学楼空教室时间轴的可读性。

## 本次调整

- 左上角改为“建筑状态 / 东教学楼”。
- 教室名称简化为“1教室”至“19教室”。
- 楼层改为左侧纵向贯通的分组标题：1—4 为一层，之后每五间为一层。
- 占用区块改为紫色到浅紫色渐变，并铺满对应行高；时间范围默认显示在色块中。
- 底部课时标头只显示数字，不再显示时间。
- 课时虚线在 1/2、3/4 等成对课时之间使用浅色分隔线。
