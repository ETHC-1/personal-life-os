# 项目工作进度

更新时间：2026-09-01

## 当前阶段

阶段 1：个人日程与待办 MVP。

## 已完成

- [x] 系统时间读取服务，支持 `Asia/Shanghai` 和 UTC 的 ISO 8601 时间。
- [x] 日历事件创建、查询、删除、时区校验和基础冲突检测。
- [x] 首页近期日程列表和新建日程表单。
- [x] 待办创建、查询、删除、完成/恢复、优先级和截止时间。
- [x] 首页待办列表和操作表单。
- [x] `/api/overview` 今日总览接口。
- [x] 首页显示当前时间、今日日程、今日课程和未完成待办数量。
- [x] 23 项 Python 测试和前端脚本语法检查通过。

## 当前进行中

- [x] 日程编辑功能。
- [x] 待办编辑功能。

## MVP 剩余事项

- [x] 日程和待办编辑后端接口。
- [x] 首页编辑交互和表单回填。
- [x] 重复日程规则（每天、每周、工作日）。
- [x] 基础提醒计算接口（暂不连接外部通知渠道）。
- [ ] 课程、日历和待办的统一时间线。
- [ ] 逾期待办与列表筛选。

## 暂不纳入当前 MVP

- PostgreSQL、Rust/Axum 正式迁移
- 用户认证和多端同步
- 移动端、桌面端和 AI 助手
- 小米手环及其他外部通知渠道

## 下一步验收标准

用户可以打开已有日程或待办，修改内容并保存；刷新页面后修改结果仍然存在；非法时间和冲突安排会返回明确错误，且不会破坏原有数据。
